# SOC Log Monitoring Project

Projeto prático voltado para monitoramento e análise de logs, simulando atividades de um analista SOC (Blue Team).

## Objetivo
Analisar logs de autenticação e identificar eventos suspeitos relacionados a tentativas de acesso não autorizado.

## Atividades realizadas
- Leitura e análise de logs
- Identificação de falhas de autenticação
- Classificação de alertas
- Documentação técnica do incidente

## Tecnologias
- Python
- Logs de autenticação (simulados)
- Markdown
